========================================================================
BLOB ANALYSIS — WHAT TO ACTUALLY READ
A focused reading guide for blob_analysis.py
========================================================================

Goal: understand the 4 functions used in blob_analysis.py. That's it.
Each section below = one doc link + ONLY the part you need from it.
Everything else on those pages is for other problems. Skip it.


------------------------------------------------------------------------
1. THE MAIN ONE — connected components  (the heart of the whole thing)
------------------------------------------------------------------------
LINK:
  https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html

This page is huge (~40 functions). IGNORE all of it except two things:

  [ ] Ctrl+F for:  connectedComponentsWithStats
      Read just its description + the parameter list.
      Remember: you give it a black/white image, it returns
        num_labels, labels, stats, centroids

  [ ] Ctrl+F for:  ConnectedComponentsTypes
      This is the table of column names for "stats". Memorize these 5:
        CC_STAT_LEFT   = x
        CC_STAT_TOP    = y
        CC_STAT_WIDTH  = w
        CC_STAT_HEIGHT = h
        CC_STAT_AREA   = pixel count   <-- the number drawn on the boxes

  SKIP: contours, moments, convex hull, Hough, shape matching — not needed.

  --> maps to: detect_blobs() in blob_analysis.py


------------------------------------------------------------------------
2. CLEANING THE MASK — morphology (open + close)
------------------------------------------------------------------------
LINK:
  https://docs.opencv.org/4.x/d9/d61/tutorial_py_morphological_ops.html

Read ONLY these 3 short sections (skip Erosion/Dilation/Gradient/Tophat):

  [ ] "Opening"   -> removes small white speckle (noise)
  [ ] "Closing"   -> fills small black holes inside a blob
  [ ] "Structuring Element" (bottom) -> getStructuringElement(MORPH_ELLIPSE,...)

  One sentence to keep: opening = clean noise, closing = fill holes.

  --> maps to: clean_mask() in blob_analysis.py


------------------------------------------------------------------------
3. MAKING THE IMAGE BLACK/WHITE — thresholding
------------------------------------------------------------------------
LINK:
  https://docs.opencv.org/4.13.0/d7/d4d/tutorial_py_thresholding.html

Read ONLY:

  [ ] Section "1. Simple Thresholding" (the very first one)
      The line you care about:
        ret, binary = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
      = "every pixel above 127 becomes white (255), else black (0)."

  SKIP: Adaptive Thresholding and Otsu's — not used here.

  --> maps to: the cv2.threshold line in clean_mask()


------------------------------------------------------------------------
4. DRAWING THE BOXES (optional — only if curious)
------------------------------------------------------------------------
LINK:
  https://docs.opencv.org/4.x/d6/d6e/group__imgproc__draw.html

Just skim the signatures for:
  [ ] rectangle()   [ ] circle()   [ ] putText()

  --> maps to: draw_blobs() in blob_analysis.py


========================================================================
IF YOU ONLY HAVE 10 MINUTES
========================================================================
Read section 1 only. Find connectedComponentsWithStats, learn that
"stats" is a table with the 5 CC_STAT_* columns. That single idea is
90% of blob analysis. The rest is just noise cleanup before it.

========================================================================
READING ORDER (easiest first)
========================================================================
  3 (threshold)  ->  2 (morphology)  ->  1 (connected components)
That follows the pipeline: black/white -> clean -> find blobs.
========================================================================
